# System Architecture – Pi Haven

Thư mục lưu các tài liệu thiết kế kiến trúc hệ thống Pi Haven theo Template 4.

## Tài liệu
- System Architecture Diagram (.drawio, .svg hoặc .png).
- Architecture Component Table (.pdf hoặc .docx).

## Phạm vi kiến trúc
Client/UI, WordPress Application/Backend, MySQL/MariaDB và External Services.

## Ghi chú
Kiến trúc mục tiêu có Payment Gateway và Smart Lock API; triển khai MVP sử dụng các phương án giả lập tương ứng.
