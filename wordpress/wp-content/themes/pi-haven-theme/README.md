
# PI HAVEN – WORDPRESS THEME SKELETON

## Mục đích
Bộ mã nguồn khởi tạo giao diện WordPress
cho dự án Pi Haven Homestay.

## Thành phần
- style.css: Khai báo và định dạng theme.
- functions.php: Cấu hình theme.
- index.php: Template hiển thị cơ bản.

## Trạng thái
Sprint 3 – Source Skeleton.

Đã chuẩn bị bộ khung mã nguồn.
Giao diện website chưa được xây dựng hoàn chỉnh.
Chưa triển khai chức năng booking tùy chỉnh.

## Định hướng tiếp theo
- Phát triển giao diện theo Wireframe.
- Tích hợp Hotel Booking Lite.
- Phát triển Room Hold 10 phút.
- Kiểm thử chức năng đặt phòng và quản trị.
