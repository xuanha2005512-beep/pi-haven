
# PI HAVEN – HOMESTAY BOOKING SYSTEM

## 1. Project Overview
Hệ thống đặt phòng trực tuyến và quản lý tập trung cho Pi Haven Homestay.

## 2. Project Objectives
- Hỗ trợ khách hàng tìm kiếm và đặt phòng trực tuyến.
- Quản lý booking và trạng thái phòng tập trung.
- Hạn chế overbooking thông qua Room Hold 10 phút.
- Hỗ trợ Self Check-in/Check-out.
- Cung cấp Dashboard quản trị.

## 3. Technology Stack
- CMS: WordPress
- Backend: PHP, WordPress Plugins
- Database: MySQL/MariaDB
- Hosting: AZDIGI
- Domain Provider: Tenten
- Version Control: GitHub

## 4. Main Features
- Room Search & Availability
- Multi-room Booking
- Room Hold & Conflict Checking
- Payment Processing (MVP: QR Simulation)
- Smart Lock Integration (MVP: Simulation)
- Booking & Room Management
- Dashboard
- Support, Review & Scripted Chatbot

## 5. Project Structure
- docs/: Tài liệu thiết kế và triển khai
- wordpress/: Theme/plugin và code tùy chỉnh
- database/: Schema và tài liệu dữ liệu
- demo/: Ảnh minh chứng và kết quả demo

## 6. Deployment
Dự án triển khai trên WordPress và hosting hỗ trợ PHP, MySQL/MariaDB.

Chi tiết cấu hình và triển khai nằm trong docs/deployment/.
